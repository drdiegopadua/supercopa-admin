# Supercopa Admin

Aplicativo de administração da Supercopa AFC (uso exclusivo da organização).

- Painel com indicadores e gráficos do campeonato
- Notícias e avisos do app
- Notificações push
- Relatório de funcionamento do site, do app e da súmula
- Prêmios (quiz e atleta destaque), backup e checklist

A página é pública, mas só funciona com login de administrador. Todos os dados vêm da API
(Supabase Edge Function) e nenhuma senha ou chave fica neste repositório.
